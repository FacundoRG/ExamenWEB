# ExamenWEB – Sistema de gestión de Ferretería

Sistema para la gestión de una ferretería: API RESTful con **Node.js + Express.js** conectada a **MySQL**, documentada con **Swagger**, y un frontend web en **React.js** que la consume.

| Carpeta | Rama | Descripción |
|---|---|---|
| `FerreteriaAPI/` | `api` | API REST (productos y categorías) + Swagger |
| `FerreteriaWeb/` | `web` | Frontend React (Vite) que consume la API |

Ver `GUIA_CONSUMIR_API.md` para instrucciones de uso.
